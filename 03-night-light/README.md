# 光敏自动小夜灯（Wokwi 仿真）

## 1. 项目目的
学习模拟传感器的读取，理解 ADC（模数转换）原理，掌握阈值判断逻辑。

## 2. 硬件连接（仿真）
- 电位器（模拟光敏电阻）中间引脚 -> GPIO 34（仅输入 ADC 引脚，不受WiFi和蓝牙影响）
- LED 正极 -> GPIO 2，负极 -> 220Ω 电阻 -> GND

## 3. 核心原理
- **ADC（模数转换器）**：真实世界的光强是连续的（模拟量），ESP32 的 `analogRead` 将 0~3.3V 的电压转化为 0~4095 的数字（数字量）。
- **分压电路**：光敏电阻随光照变化阻值，与固定电阻串联，将阻值变化转为电压变化，ADC 读取的就是这个电压。
- **阈值判断**：设定 2000 为界限，低于此值认为“环境暗”，高于此值认为“环境亮”。

## 4. 代码解析
int lightValue = analogRead(LDR_PIN); // 读取 0~4095 的数字量
if (lightValue < THRESHOLD) {
    digitalWrite(LED_PIN, HIGH);      // 暗 -> 开灯
} else {
    digitalWrite(LED_PIN, LOW);       // 亮 -> 关灯
}
