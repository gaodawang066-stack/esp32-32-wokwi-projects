\# ESP32 PWM 呼吸灯与按键控制



\## 1. 项目目的

理解 PWM原理，学习如何通过占空比控制 LED 亮度，并掌握按键消抖与简单的状态机逻辑。



\## 2. 硬件连接

\- ESP32 开发板

\- LED 正极 -> GPIO 4，负极 -> 220Ω 电阻 -> GND

\- 按键一端 -> GPIO 5，另一端 -> GND



\## 3. 核心原理

\- \*\*PWM\*\*：通过极快地开关引脚，用“高电平占总时间的比例”来模拟不同的平均电压，从而实现 LED 的呼吸效果。

\- \*\*按键消抖\*\*：机械按键按下时会有几十毫秒的抖动，代码中使用了 `millis()` 函数进行软件延时消抖，防止一次按下被误读为多次。

\- \*\*状态机\*\*：使用 `enum` 定义了四种模式（关、常亮、闪烁、呼吸），通过按键循环切换。
