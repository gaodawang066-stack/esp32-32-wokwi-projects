# ESP32 HTTP Server 网页控制灯（Wokwi 仿真）

## 1. 项目目的
初步探索物联网（IoT），学习 ESP32 的 Wi-Fi 连接与 WebServer 搭建，理解 HTTP 请求、路由回调与前后端交互的底层逻辑。

## 2. 硬件连接（仿真）
- ESP32 开发板
- LED 正极 -> GPIO 2，负极 -> 220Ω 电阻 -> GND

## 3. 核心原理
- **IP 地址与端口**：ESP32 成功连接 Wi-Fi 后，路由器会为其分配一个局域网 IP。HTTP 服务默认监听 80 端口。
- **路由与回调函数**：代码中使用 `server.on("/on", handleOn)` 注册路由。当浏览器请求 `/on` 路径时，触发对应的回调函数，改变 GPIO 2 的电平，实现开灯。

**踩坑记录（环境限制说明）：**
在 Wokwi 仿真中运行代码后，串口成功打印出了 IP 地址。但尝试在电脑浏览器中输入该 IP 时无法访问。经查阅 Wokwi 官方文档发现：Wokwi 免费版公共网关仅支持 ESP32 访问外网，不支持外部浏览器反向访问模拟器内部的 IP。

**后续解决方案：**
代码逻辑已完全跑通，后续购买实物 ESP32 后，只需烧录相同代码，即可在同一局域网下访问。

## 5. 个人思考与收获
这次通过 ESP32 让我真正看到了硬件是如何作为服务器响应浏览器的。虽然受限于免费仿真环境未能实际在浏览器点开网页，但我彻底弄懂了从“浏览器发起 GET 请求 -> ESP32 解析路由 -> 执行硬件控制”的完整闭环。
